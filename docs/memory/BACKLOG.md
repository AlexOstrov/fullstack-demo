### Прогресс по B4

- R-3 (env `AI_PRESET_*`, `GAME_TTL_MINUTES`) и R-4 (маппинг `Difficulty.CUSTOM → AiSettings`) — **закрыты в Sprint 3** (`AiProperties`/`GameProperties`, `AiSettingsFactory`; ADR-0017, F-013/F-015).
- R-6, частично: демо-`items` удалены (миграция `V2__drop_items`, ADR-0009/R-6) — **закрыто в Sprint 3**.
- R-2 (`score`/`depth` при обрыве первой итерации) и оставшаяся часть R-6 (дубль копирования доски, мелочи тестов) — **закрыты в B4**: при `depth = 0` отдаётся статическая оценка выбранного хода, `MoveGenerator` мутирует доску с откатом в `finally`, имя/сообщение теста исправлены (F-026, ADR-0026).
- R-5 — **закрыт в Sprint 4.3** (`style`/`emotion` в `LlmComment`, F-018, ADR-0020).
- R-7 (профилирование мобильности) — **закрыт в B4**: добавлены замеры плотного миттельшпиля и `PositionEvaluator` (~1.6 µs/eval), поиск укладывается в бюджет с большим запасом (F-026, ADR-0026).
- S4.1 (микросервис `llm-service` к Ollama) — **Done** (F-016, ADR-0018).
- S4.2 (интеграция `game-service` с `llm-service`) — **Done** (F-017, ADR-0019).
- S4.3 (комментарии со стилем и эмоцией) — **Done** (F-018, ADR-0020).
- S4.4 (сохранение комментариев LLM в `llm_comments`) — **Done** (F-019, ADR-0021).
- S4.5 (лайки комментариев LLM) — **Done** (F-020, ADR-0022); B2 закрыт — API лайков реализовано.
- S7.1–S7.3 (Docker и интеграция) — **Done** (F-023, ADR-0023).
- Sprint 9 (стабилизация Docker-запуска) — **Done** (F-024, ADR-0024): исправлены контексты сборки, путь jar, `npm ci` во frontend, старт `llm-service` (`@Autowired`, `Duration`-ключи), вызов Ollama `/api/chat` через `messages`, SSE-парсер `data:` без пробела.

### Прогресс по B1, B3, B5 (закрыты)

- **B1** — `GET /api/tournament` (агрегат `tournament` по победителю), блок «Счёт побед» в левом сайдбаре, обновление после завершения партии; F-029, ADR-0028.
- **B3** — fallback берёт случайный сохранённый комментарий того же стиля из `llm_comments` (только `liked=true` и `llm_model != null`), при пустой/недоступной БД — детерминированный текст; F-027, ADR-0027.
- **B5** — промпт с нотацией `c3–d4`/`c3×e5` и требованием русского языка, пост-фильтр `CommentTextSanitizer` (иероглифы/латиница/разметка/длина), ответы с иероглифами уходят в fallback; F-028, ADR-0027.
